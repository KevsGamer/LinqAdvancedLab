# LinqAdvancedLab

Proyecto académico desarrollado en .NET utilizando LINQ avanzado, Entity Framework Core y SQL Server (Northwind).

## 🧠 Objetivo
Aplicar consultas LINQ avanzadas sobre una base de datos real y validar su funcionamiento mediante pruebas unitarias.

## 🛠️ Tecnologías
- .NET
- C#
- Entity Framework Core
- SQL Server (Northwind)
- LINQ
- xUnit
- EF Core InMemory

## 📌 Funcionalidades
- Consultas LINQ con:
  - Where
  - OrderBy
  - Select
  - Join
  - Take
- Impresión del SQL generado
- Patrón Repositorio Genérico
- Pruebas unitarias con base de datos en memoria

## 🧪 Pruebas
Las pruebas se ejecutan usando xUnit y EF Core InMemory para evitar dependencia de SQL Server.

## ▶️ Ejecución
1. Ejecutar el proyecto `LinqAdvancedLab.Console`
2. Ejecutar pruebas desde:
   Test → Ejecutar todas las pruebas
